# PPT 생성 프롬프트 - AI를 이용한 도로안전망 구축 플랫폼 "Bros"

---

## 📊 프로젝트 소개

**"Bros"** - **AI를 이용한 도로안전망 구축 플랫폼**

"Bros"는 **소셜 기능과 AI 기반 도로 안전 정보를 결합한 종합 플랫폼**입니다.  
사용자들이 도로의 위험 지점(hazard)을 공유하고, 커뮤니티를 형성하며, 안전한 경로를 탐색할 수 있습니다.

### 🎯 핵심 가치 제안
- **실시간 도로 위험 정보 공유** - 커뮤니티 기반 hazard 리포팅
- **AI 기반 안전 경로 계산** - OSRM을 통한 최적 경로 추천
- **소셜 네트워킹** - 팔로우, 게시물, 댓글, 멘션으로 커뮤니티 활성화
- **지역 기반 서비스** - Reverse Geocoding, 장소 검색, 로컬 탐색
- **포인트 기반 경제 시스템** - 코스메틱 스토어, 상품 구매, 카카오페이 결제

### 🔧 기술 스택

**Frontend:**
- **프레임워크**: React 19 RC + Vite (번들링)
- **상태관리**: Redux Toolkit + Redux Query
- **라우팅**: React Router v6
- **UI 라이브러리**: Bootstrap 5 + React Bootstrap
- **지도**: Leaflet + React Leaflet
- **HTTP 클라이언트**: Axios (JWT 자동 헤더 삽입)
- **인증**: JWT + OAuth (Google, Kakao, Naver)
- **추가 라이브러리**: Draft.js (에디터), Moment (시간), Leaflet Routing Machine

**Backend:**
- **프레임워크**: Flask 2.x
- **ORM**: SQLAlchemy + Flask-Migrate
- **인증**: Flask-JWT-Extended (JWT 기반)
- **데이터베이스**: MySQL / PostgreSQL
- **이미지 처리**: 업로드, 압축, 저장
- **외부 API 연동**: 
  - OSRM (경로 계산)
  - Kakao/Google/Naver Maps (지오코딩)
  - Kakao Pay (결제)
  - OAuth (Google, Kakao, Naver)

## 🗄️ 데이터베이스 구조

### 주요 테이블 (13+)

```
users
├─ user_id (PK)
├─ username, email, password_hash
├─ nickname, profile_img
├─ oauth_type (Google/Kakao/Naver)
├─ points, account_type (USER/ADMIN)
└─ created_at, updated_at

posts
├─ post_id (PK)
├─ user_id (FK → users)
├─ content, image_url
├─ like_count, reply_count
└─ created_at, updated_at

replies
├─ reply_id (PK)
├─ post_id (FK → posts)
├─ user_id (FK → users)
├─ parent_reply_id (FK → replies, 대댓글용)
├─ content
└─ created_at, updated_at

follows
├─ follower_id (FK → users)
├─ following_id (FK → users)
└─ created_at

likes
├─ user_id (FK → users)
├─ post_id or reply_id
└─ type (POST/REPLY)

notifications
├─ notification_id (PK)
├─ user_id (FK → users)
├─ type (LIKE/REPLY/FOLLOW/MENTION)
├─ actor_id (FK → users)
├─ read_at
└─ created_at

hazards (도로 위험 지점)
├─ hazard_id (PK)
├─ user_id (FK → users)
├─ latitude, longitude
├─ hazard_type (POTHOLE/ACCIDENT/DEBRIS)
├─ severity (1-5)
├─ description, image_url
├─ confirmed_count
└─ created_at, updated_at

places
├─ place_id (PK)
├─ user_id (FK → users)
├─ name, address
├─ latitude, longitude
├─ category
└─ created_at

routes
├─ route_id (PK)
├─ user_id (FK → users)
├─ start_point, end_point
├─ route_data (JSON: 경로 좌표)
├─ hazard_count
└─ created_at

cosmetic_items
├─ item_id (PK)
├─ name, description
├─ price (포인트)
├─ image_url
├─ category
└─ created_at

user_cosmetic_state
├─ user_id (FK → users)
├─ item_id (FK → cosmetic_items)
├─ equipped (boolean)
└─ acquired_at

products
├─ product_id (PK)
├─ name, description
├─ price, stock
├─ image_url
├─ sponsor_id
└─ created_at

payments
├─ payment_id (PK)
├─ user_id (FK → users)
├─ product_id (FK → products)
├─ amount, status
├─ kakao_tid, created_at
└─ updated_at

mentions
├─ mention_id (PK)
├─ mentioned_user_id (FK → users)
├─ actor_id (FK → users)
├─ post_id or reply_id
├─ type (POST/REPLY)
└─ created_at

reports
├─ report_id (PK)
├─ reporter_id (FK → users)
├─ target_type (POST/REPLY/USER)
├─ target_id
├─ reason, status
└─ created_at
```
